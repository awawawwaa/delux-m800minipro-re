Delux DPI Configurator

Controls the mouse's DPI stages without the official software. Built specifically for the Delux M800 Mini Pro running Delux's "competitive" firmware (required to expose the Sensor frame rate / mode setting).
This mouse exposes its config report inside a "Mouse" HID collection, which browsers block for security reasons (WebHID zeroes out those reports). So instead of connecting directly through the browser, this page talks to a local bridge that runs outside the browser and has full HID access:

powershell -ExecutionPolicy Bypass -File scripts\Start-DpiBridge.ps1

Keep the bridge window open while using this page.
